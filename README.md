# Suriya17.github.io

Personal site, built with [Hugo](https://gohugo.io/) and deployed to GitHub Pages by `.github/workflows/hugo.yml` on every push to `main`.

- **Edit content:** `data/resume.yaml`
- **Layout:** `layouts/index.html` (+ `layouts/partials/entry.html`)
- **Styles:** `assets/style.css` (minified and fingerprinted at build time)

Local preview: `hugo server`, then open http://localhost:1313.
